For the past two years, frontier model labs treated the context window as their primary marketing weapon. Each release promised longer horizons: from 32,000 tokens to 128,000, then one million, and eventually two million. The pitch to enterprise software teams was straightforward. Instead of designing complex retrieval architectures, maintaining vector indices, or pruning state machines, engineers were told to dump entire code repositories, quarterly financial filings, and conversational transcripts directly into the prompt. The retail pricing seemed to bless this practice. API providers continued to charge a flat headline price per million tokens, creating the impression that generating an answer against a two-hundred-thousand-token prompt carried the same marginal compute expense as generating an answer against a five-hundred-token query.

That flat price is an accounting fiction. A research team at NVIDIA led by Peter Belcak recently published a measurement study titled "You don't need long context" that quantifies the physical cost hidden beneath the retail invoice. Converting measured peak decode throughput on on-demand H100 clusters into dollar costs, the authors found that generating output tokens on an existing key-value cache scales sharply with context depth. On popular open-weight architectures, generating one million output tokens at a context window of 256,000 tokens costs between 3.6 and 7 times more than generating those same tokens at a 16,000-token window. For GLM 5.2 the cost rose 3.6 times, for Kimi K2.6 it grew 5.6 times, and for Qwen 3 Coder Next it jumped sevenfold, climbing from under 1.50 dollars to over ten dollars per million generated tokens.

The physical driver of this penalty is familiar to anyone who profiles hardware memory access. Generating a token in an autoregressive transformer requires streaming the entire key-value cache from high-bandwidth memory to the tensor cores for every decoding step. As the prompt expands, the memory footprint balloons, available GPU memory bandwidth saturates, and inter-token latency roughly doubles. The server spends most of its clock cycles moving past tokens across memory buses rather than performing arithmetic.

Marketing departments frequently point to prompt caching as the economic antidote, but caching solves only the prefill phase. Once a prefix is processed, retaining a two-hundred-thousand-token cache in volatile GPU memory still locks up scarce high-bandwidth memory capacity. More importantly, prompt caching provides zero relief during autoregressive generation. Every single generated token must still evaluate cross-attention against the entire active cache, paying the full memory bandwidth toll on every decoding pass.

Model providers have absorbed this penalty to protect customer acquisition. By maintaining uniform token pricing regardless of context depth, hyperscalers and labs effectively run a massive cross-subsidy. Short-prompt API users paying standard rates subsidize enterprise workloads that repeatedly pass two-hundred-thousand-token contexts into multi-turn agent loops. In a competitive market, cross-subsidies survive only as long as capital remains cheap or gross margins stay wide enough to hide the bleed.

The defensive justification for this hardware drain was always cognitive necessity: long tasks supposedly demand long contexts. Belcak and his coauthors tested that claim against standard benchmarks, including long-horizon software engineering and document extraction. Their findings undermine the premise. By applying disciplined semantic compaction, distilling conversational progress, verified facts, and unresolved subgoals into a structured state after each step, frontier models preserved or slightly improved baseline accuracy while keeping live context bounded. The authors noted that this result mirrors Alan Turing's 1936 definition of computability, which proved that any computable function can be evaluated by examining a bounded amount of input at any single moment while updating a finite internal state.

The emergence of this paper from NVIDIA carries its own institutional irony. NVIDIA is the primary supplier of the high-bandwidth memory accelerators that hyperscalers buy to host oversized key-value caches. Yet its systems researchers are demonstrating that treating the context window as working memory is an exceptionally wasteful use of silicon.

The economic implications for enterprise software architecture are direct. When a company builds an autonomous coding agent or customer operations pipeline on the assumption of cheap, unbounded context, it exposes itself to severe repricing risk. If API providers eventually introduce depth-dependent pricing to reflect their true generation costs, brute-force prompt architectures will experience an overnight cost explosion. Teams that invest early in structured state maintenance and semantic compaction not only secure lower latency today, but also insulate their gross margins against the inevitable collapse of flat-rate token pricing.
